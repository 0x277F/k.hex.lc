Gorenstein and Non-Gorenstein Singularities


5 June 2025

This is a student seminar talk I gave back in December, mostly to try and understand the correspondence between classes of not-quite-regular rings and the singularities of their spectra.It was shamefully written pretty much just for myself, but I did also mislead some of my analyst friends into attending, so I was trying to be more fun and casual than technical. Since then, I’ve both passed my quals and lost the original notes I wrote for this talk, so I really need you to trust me that it was better at the time.

In commutative algebra, we have an idea of how “nice” a local ring might be – in ascending order, the usual list starts with Cohen-Macaulay rings, then Gorenstein rings, then complete intersection rings, then regular local rings. Recalling the definitions, a local ring (A,𝔪,k) is Cohen-Macaulay if dim⁡A = depth ⁡ R, and A is regular if 𝔪 is generated by dim⁡A elements. A is a complete intersection if A¯ is the quotient of a regular local ring by an ideal (𝒙), where 𝒙 is a regular sequence.

The three kinds of ring we’ve defined so far have intuitive geometric interpretations as well. On a variety (over a perfect field, for technical reasons), the local ring at a point p is regular if and only if the variety is smooth, where you can imagine “smooth” meaning smooth in the analytic sense:

Letting p = (0,0) ∈ 𝔸2 be the point corresponding to (x,y) in k[x,y], 𝒪X,p on the left is regular, but 𝒪Y,p on the right is not. Both are complete intersections, though, since their defining ideals are generated by one element and k[x,y] is a regular domain. I would say that Y has a complete intersection singularity at p.

Question. To understand the geometry encoded in Cohen-Macaulay rings, it’s convenient that the Krull dimension of the ring matches the intuitive idea of dimension as a variety – but what does the depth represent?

I’ve procrastinated in defining what a Gorenstein ring or a Gorenstein singularity is, so – for a local ring (A,𝔪,k) of dimension n, the following are equivalent:

(i)
A is Gorenstein;
(ii)
injdim ⁡ A < ∞;
(iii)
injdim ⁡ A = n;
(iv)
Ext ⁡ Ai(k,A) = δnik;
(v)
Ext ⁡ Ai(k,A) = 0 for some i > n;
(vi)
A is Cohen-Macaulay and Ext ⁡ An(k,A) = k;
(vii)
A is isomorphic to its own canonical module ωA.

Geometrically, Gorenstein singularities are more mysterious. For example, the variety Y = Spec ⁡ k[x,y]∕(𝑥𝑦) is Gorenstein (indeed, it is a complete intersection), but the variety X = Spec ⁡ k[x,y,z]∕(𝑥𝑦,𝑥𝑧,𝑦𝑧) has a non-Gorenstein singularity at the origin:

Heuristically, we might expect this, but only because it’s geometrically evident that X isn’t a complete intersection – X has codimension 2 but its defining ideal has 3 generators. To verify directly that X isn’t Gorenstein is a little more laborious and, concerningly, attempting to verify criteria (iv) or (v) might require arbitrarily many computations. Instead, we can compute the canonical module of 𝒪X,0 and determine that it is different than 𝒪X,0 itself.

Let R = k[x,y,z] – first, we’ll inspect the quotient map R →𝒪X → 0 and extend it to a free resolution F∙. We start with

R3 →( 𝑥𝑦 𝑦𝑧 𝑥𝑧 )R →𝒪X → 0.

At the next iteration, we get

F∙ : R2 →( −z 0 y −y 0 x )R3 →( 𝑥𝑦 𝑦𝑧 𝑥𝑧 )R →𝒪X → 0

because if R2 is generated by {e1,e2}, then ( −ze1 ye1 − ye2 xe2 ) ( 𝑥𝑦 𝑥𝑧 𝑦𝑧 ) = 0. This map has trivial kernel, so it completes our free resolution. Next, we apply Hom ⁡ (−,R) to obtain the dual resolution

F∙ : 0 →𝒪 X → R →d0R3 →d1R2 → 0

This is an acyclic resolution of 𝒪X with respect to the functor Hom ⁡ (−,R), so Ext ⁡ i(𝒪X,R) = Hi(Hom ⁡ (F∙,R)). Now, R is a 3-dimensional regular ring and 𝒪X is a 1-dimensional R-algebra, so a theorem1 tells us that ω𝒪X,0 is isomorphic to Ext ⁡ 2(𝒪X,0,R(x,y,z)), which we now know is the cokernel of the map d1. For linear algebra reasons, d1 is the transpose of the map ( −z 0 y −y 0 x ) in the F∙ resolution. Since 𝒪X is the cokernel of ( 𝑥𝑦 𝑦𝑧 𝑥𝑧 ), and these aren’t the same, we’ve shown that 𝒪X,0 isn’t isomorphic to ω𝒪X,0, so 𝒪X,0 isn’t Gorenstein.

There is an alternate way of showing that 𝒪X,0 isn’t Gorenstein that is more specific to this particular ring, but may be more illuminating combinatorially. Given a simplicial complex Δ and a field k, we can define a ring R to be the free commutative k-algebra generated by the vertex set of Δ, and an ideal I generated by the square-free monomials who don’t correspond to faces of the complex. The quotient R∕I is called the Stanley-Reisner ring of the complex.
